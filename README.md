# @pragmatic-tech-ai/todl-identity

Engine-layer identity management contracts: principal, realm (the boundary accounts, sessions and grants belong to) and session value types plus the swappable provider-pack seams. The package depends only on `@pragmatic-tech-ai/todl-runtime`, and is consumed by the platform server and desktop Plexus, which supply the concrete provider packs.
